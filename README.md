## 🚀 Overview
**PsiMan** is an enterprise-grade control panel designed to automatically manage, monitor, and deploy isolated Psiphon nodes. It replaces tedious command-line setups with a stunning, high-performance web dashboard inspired by iOS Dark Mode and Cyberpunk aesthetics.

## ✨ Features
- 🎨 **Quantum UI:** Beautiful 3D animated backgrounds with advanced glassmorphism (frosted glass) cards.
- 🌍 **35+ Global Nodes:** Instant deployment of connections across North America, Europe, and Asia-Pacific.
- 📡 **Live Network Radar:** Real-time scanning of the global Psiphon network to discover undocumented or newly added regions (marked with ✨NEW).
- 🧪 **Isolated Test Probe:** Securely test any country's connection and retrieve the assigned IP without affecting your main traffic ports.
- 📊 **Live Telemetry:** Real-time, accurate CPU and RAM monitoring straight from the Linux kernel.
- 🔒 **Secure Auth:** Encrypted session-based login with customizable credentials and ports.

## ⚡ Installation (One-Click)
Run this single command on your Linux server (Ubuntu/Debian) as `root`. The installer will automatically prompt you for your desired **Port**, **Username**, and **Password**.

```bash
bash <(curl -s (https://raw.githubusercontent.com/a-salemi/Psiman/main/install.sh))
```

## 🛠️ Usage
1. Once installed, open your browser and navigate to:
   `http://YOUR_SERVER_IP:PORT` (Default port is `8585` if you didn't change it).
2. Log in using the Username and Password you defined during the installation.
3. Enjoy the ultra-smooth dashboard! 🍏

## 🛑 Requirements
- A clean Linux Server (Ubuntu 18.04/20.04/22.04 or Debian)
- Root privileges
- Standard Python3 environment (automatically handled by the installer)
